# Frontend Portfolio Demos

A collection of modern, responsive, and interactive frontend website demos built with vanilla web technologies. 

> **Note:** Both projects in this repository are **fictional demonstration projects** created for portfolio and educational purposes. Any businesses, properties, menus, prices, or services featured are entirely made up.

---

## 📁 Projects Overview

### 1. Haven Estates (`/realestate`)
A boutique real estate agency website featuring an editorial design, custom typography, and interactive property browsing.
* **Key Features:**
  * Interactive property search and real-time filtering (by price, property type, and keywords).
  * `localStorage`-backed "Saved Properties" / favorites system.
  * Quick-view modal popups with interactive image galleries and thumbnail navigation.
  * Client-side form validation for property enquiries.
  * Responsive layout with a custom mobile navigation menu.
* **Tech Stack:** HTML5, CSS3, Vanilla JavaScript

### 2. Ember & Oak (`/restaurant`)
A single-page website for a fictional contemporary restaurant highlighting seasonal dishes and warm hospitality.
* **Key Features:**
  * Clean, appetizing visual layout showcasing featured menu items.
  * Interactive UI elements powered by vanilla JavaScript.
  * Responsive mobile-friendly styling.
* **Tech Stack:** HTML5, CSS3, Vanilla JavaScript

---

## 🚀 Getting Started

Since these are static frontend projects, no build tools or local servers are required.

1. Clone or download this repository.
2. Navigate into either project folder (`realestate` or `restaurant`).
3. Open `index.html` in any web browser:
